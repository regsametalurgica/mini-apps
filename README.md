# Mini Apps - Regsa Metalúrgica

Projeto desenvolvido para uso interno da empresa Regsa Metalúrgica como conjunto de ferramentas de apoio.

## Tecnologias Principais:
- **Frontend**: React + Typescript + TailwindCSS + Vite
- **Backend**: Node.js + Express
- **Banco de dados**: PostgreSQL
